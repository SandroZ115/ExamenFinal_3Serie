# CRUD Alumnos – ASP.NET Core MVC + Entity Framework Core

Aplicación web MVC que implementa un CRUD básico de alumnos usando scaffolding con Entity Framework Core y SQL Server.

## Tecnologías

- ASP.NET Core MVC (.NET 10)
- Entity Framework Core 10 (SqlServer, Tools)
- SQL Server
- Visual Studio 2026
